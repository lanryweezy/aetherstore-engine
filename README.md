## 🏗️ Architectural Excellence

The AetherStore backend has been refactored for enterprise-grade production:

1.  **Task-Oriented Orchestration:** The `AdvancedAIService` delegates to specialized orchestrators (`Vision`, `Behavioral`, `Cognitive`, etc.).
2.  **Persistent Persistence:** A robust **SQLAlchemy SQLite** database ensures all store, product, and AI metadata survive restarts.
3.  **Observability Layer:** Structured JSON logging and latency tracking for all 25 pillars.
4.  **Modular API:** Specialized FastAPI routers for AI, Commerce, and Social intelligence.
5.  **Centralized Config:** Pydantic-based settings for managing massive model paths and environment variables.

## 🚀 Getting Started

### One-Click Production Launch (Docker)
The entire 25-pillar ecosystem is containerized for instant portability.

```bash
docker-compose up --build
```
*Access the platform at `http://localhost/` and the AI Center at `http://localhost:8000/static/super_intelligence_demo.html`*

### Manual Local Setup
1. **Backend:**
   ```bash
   cd backend
   pip install -r requirements.txt
   python main.py
   ```
2. **Frontend:**
   ```bash
   cd frontend
   npm install
   npm run build
   ```

### Automated Asset Setup
Download the required high-performance weights for all foundation models:
```bash
python scripts/download_weights.py
```
